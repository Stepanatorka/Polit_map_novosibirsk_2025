# Интерактивная политическая карта Новосибирской области

Интерактивное настольное приложение на Python для визуализации результатов выборов в Новосибирской области.

Приложение позволяет просматривать карту избирательных округов, выбирать отдельные округа и получать информацию о результатах голосования.

## Возможности

- интерактивная карта Новосибирской области;
- выбор отдельных избирательных округов;
- отображение результатов голосования;
- визуализация результатов с помощью графиков;
- просмотр общей статистики;
- масштабирование и перемещение карты;
- отдельный просмотр округов Новосибирска.

## Технологии

- Python
- PyQt5
- NumPy
- Pillow
- Matplotlib
